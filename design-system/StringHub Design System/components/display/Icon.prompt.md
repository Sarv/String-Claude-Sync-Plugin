Boxicons 2.1.4 glyph wrapper — the only icon set StringHub uses; colour follows currentColor.
```jsx
<Icon name="search" size={16} />  <Icon name="flag" solid />  <Icon name="bxl-whatsapp" size={14} />
```
Never mix other icon libraries. Check a name exists in 2.1.4 (e.g. `bx-bolt` doesn't; use `bx-bolt-circle`).
